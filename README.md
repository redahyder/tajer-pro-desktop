# تاجر برو — تطبيق ويندوز

تطبيق سطح المكتب لمنصة **تاجر برو** (نظام المبيعات والمخزون ونقطة البيع والمتجر الإلكتروني).

## ⬇️ التحميل

**[تحميل ملف التثبيت (TajerPro-Setup.exe)](https://github.com/redahyder/tajer-pro-desktop/releases/latest/download/TajerPro-Setup.exe)**

أو [النسخة المحمولة بدون تثبيت](https://github.com/redahyder/tajer-pro-desktop/releases/latest/download/TajerPro-Portable.exe) — وكل الإصدارات في صفحة [Releases](https://github.com/redahyder/tajer-pro-desktop/releases).

بعد التثبيت سجّل دخولك باسم المستخدم وكلمة المرور الخاصة بحسابك.
ليس لديك حساب؟ أنشئ حساباً من [tajer-pro-iota.vercel.app/signup](https://tajer-pro-iota.vercel.app/signup).

> قد يظهر تحذير Windows SmartScreen لأن البرنامج غير موقّع رقمياً — اضغط "معلومات إضافية" ثم "تشغيل على أي حال".

## المزايا
- يفتح نظامك مباشرة (نفس الحساب والبيانات الموجودة على الموقع).
- طباعة مباشرة بدون نافذة: طابعة للإيصالات، وطابعة للفواتير A4، وطابعة لملصقات الباركود، وطابعة لملصقات الشحن — من "إعدادات التطبيق والطابعات" (`Ctrl+,`). مقاس الورق يُحسب تلقائياً.
- عدد نسخ الإيصال، التشغيل مع ويندوز، ووضع ملء الشاشة لجهاز الكاشير.
- صفحة "لا يوجد اتصال" تعود تلقائياً عند رجوع الإنترنت.
- اختصارات: `Ctrl+1` لوحة التحكم، `Ctrl+2` نقطة البيع، `F5` تحديث، `F11` ملء الشاشة.

تحديثات النظام نفسه (الصفحات والمزايا) تصل للتطبيق فوراً بدون إعادة تثبيت.

## التطوير والإصدار
```bash
npm install
npm start                                   # يفتح الموقع الأساسي
TAJER_SERVER_URL=http://localhost:3000 npm start   # أو خادم محلي
```
**إصدار نسخة جديدة:** غيّر `version` في `package.json` وارفع التغيير إلى `main` — يبني GitHub Actions ملفات ويندوز تلقائياً وينشرها في Releases بوسم `vX.Y.Z`، ويبقى رابط التحميل أعلاه يشير لآخر نسخة.
